# Simple Data Engineering Project

ETL pipeline sederhana untuk memproses data harga pangan Indonesia.

## Pipeline
CSV → Extract → Transform → Load → SQLite

## Dataset
Data harga pangan bulanan dari Badan Pangan Nasional (data.go.id)

## Tech Stack
- Python
- Pandas
- SQLite3

## Struktur Folder
etl-project/
├── data/          ← file CSV
├── scripts/       ← notebook ETL
└── output/        ← database SQLite
